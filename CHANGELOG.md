### Changed
- Documentation translated to English.
- Live view: plays the camera's LL-HLS stream (`urlTransmision`) with `video_player` behind the `ReproductorVivo` interface, replacing the WebSocket JPEG relay (`web_socket_channel` removed). Chips «Video», «Video y postura» and «Solo postura» change the stream mode (`PATCH /api/vista-en-vivo/{sesionId}`, `modo` in the `POST`), each explained from the prototype's «Ves la Sala y la postura de Rosa en este momento». Debug Android builds allow plain HTTP to local hosts only, and iOS allows local networking, for the local streaming service. API contract section 4 follows the live view v2 specification.
- The older adult form asks for «Edad» (50–120, prototype messages), shown as «Rosa Huamán, 78 años» and «78 años · Vive solo(a)»; the stored phone is sent back on profile updates. `edad`, `telefono`, `instaladaEn` and `noConfiableDesde` are now in the API contract.
### Fixed
- Live view: a playback error or a stream that stops advancing for 10 s, or whose first frame takes over 20 s, is no longer ignored: the session ends and the disconnected view offers «Ver en vivo», which opens a new one. Opening retries while the camera starts publishing.
- Live view: the whole 4:3 frame is shown at its own aspect ratio instead of being cropped to 3:4.
- Live view: the session is ended with `DELETE` when the app goes to the background, and a new one opens on return.
- Live view: `409 SIN_CONSENTIMIENTO` shows «La cámara está detenida» and reloads the household (CA-05.2).
- Revocation: `404 SIN_CONSENTIMIENTO` reloads Privacidad, which shows «Sin consentimiento», instead of an error toast; the card title no longer overflows on narrow screens.
