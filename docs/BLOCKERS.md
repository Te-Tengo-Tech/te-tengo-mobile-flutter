# Blockers

Tasks that cannot be finished without an outside decision or credential. Agents add an entry here, keep working on the next task, and never invent the missing value.

| Task | What is missing | Who decides | Date |
|---|---|---|---|
| Real push notifications (T12) | The Firebase project and its config files (`android/app/google-services.json`, `ios/Runner/GoogleService-Info.plist`, not committed) and, for iPhones, an Apple Developer Program team with an APNs key uploaded to Firebase. The Gradle plugin, the Xcode copy phase, the entitlements, the permission prompt and the APNs-aware token registration are ready; steps in [FIREBASE.md](FIREBASE.md). Without the files push is unavailable and everything else runs; tests use `NotificacionesPushFalsas`. The backend must deliver iOS pushes through FCM, because the app registers FCM tokens on both platforms | Team | 2026-10-07 |
| T05, T26 Email links | The contract does not define the links the backend emails.
